# KubePhos v0.1.17

## Live experiment dashboard

- Open a live Grafana dashboard from a run or from the cluster details, scoped to
  the experiment namespace and start time.
- Follow throughput, response times, failures, SLO compliance, service metrics,
  replicas, pod scheduling, and resource usage with automatic refresh.
- Install or update the dashboard on demand, including on existing single
  clusters. The KubePhos host must be able to reach the managed Grafana endpoint.

## Resources and deployment diagnostics

- Optionally retain Online Boutique's upstream CPU and memory requests and
  limits, with explicit settings overriding only the fields provided. The
  default continues to omit upstream resource settings.
- Reject requests that exceed a retained upstream limit.
- Report pods that remain unschedulable before the full readiness timeout,
  including the scheduler's reason. Placement constraints receive a 30-second
  grace period; capacity shortages receive two minutes.

## Runs, comparisons and navigation

- Select and delete multiple completed runs, preserving ownership checks and
  keeping failed deletions selected for retry.
- Identify comparison sources that were deleted or are no longer shared, with
  an edit action to repair the selection.
- Improve the collapsible sidebar, resource tables, resource readouts, request
  forms and action layouts.

## Upgrade

Back up the installation and wait for active work to finish. Set
`KUBEPHOS_VERSION=v0.1.17` in the installation `.env`, then run `./update.sh` from
this release's archive or checkout. Add `--directory /path/to/installation` for a
custom installation path. If using a temporary local image, restore
`KUBEPHOS_IMAGE=ghcr.io/unict-cclab/kubephos` first.

Existing configurations, experiments, results and credentials are retained. No
database migration is required. The managed observability plugin is updated to
0.2.7; managed component image versions are unchanged from v0.1.16. Live dashboard
access is currently supported for single clusters.

## Verification

Go tests and static analysis; frontend regression tests, production build,
bundle and theme checks. The GitHub Checks workflow gates publication and also
checks PostgreSQL integration, installer behavior and dependency vulnerabilities.
