# KubePhos v0.1.2

## Initial administrator password

New installations create the initial administrator with a temporary password.
At first login, Keycloak requires a new password before granting access to the
platform. Subsequent logins use the replacement password.

The installer saves the initial username, email and temporary password in:

```text
~/.local/share/kubephos/credentials.json
```

With a custom installation directory, the file is
`<installation-directory>/credentials.json`. The installer prints its exact path.
The file retains only the initial credentials and is not updated after the
password change.

Existing accounts keep their current passwords. Rerunning the installer or
updater does not reset passwords or require an additional change.

## Documentation and checks

- Clarified running `./update.sh` directly from a clone or extracted release.
- Documented the credentials file location and mandatory first-login change in
  the README and installation guide.
- Added regression coverage for temporary versus regular user credentials.
- Verified the login flow against a disposable Keycloak installation: access is
  blocked until the password changes, the initial password is then rejected,
  and the new password permits subsequent login.

To upgrade, set `KUBEPHOS_VERSION=v0.1.2` in the installed `.env` and run
`./update.sh` from this release directory (or a clone at `v0.1.2`). Use
`--directory /path/to/installation` for a custom installation path.
