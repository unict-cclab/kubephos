# KubePhos v0.1.13

## Comparisons

- Compare completed experiments using all successful runs from each experiment,
  including experiments with different repetition counts. Original single-run
  results and comparative configuration execution remain available.
- Set a plot label and color for each experiment without renaming its source.
  Matching experiment names no longer receive numeric suffixes.
- Add experiments and configurations through a searchable selection dialog, with
  a creator filter initially set to the current user. Selected items cannot be
  added twice. Experiment search includes the full accessible result history.
- Show selected items in full-width tables only after an item has been added.
- Prepare comparison datasets, statistics and plots in a background web worker
  to keep navigation responsive. Dataset downloads support gzip compression.

## Experiment configuration

- Configure multiple external endpoints with labels and fixed or phased traffic
  distribution. Existing single-endpoint configurations remain supported.
- Suggest editable run names as `configuration-DD/MM/YYYY-HH:mm`, using the local
  start time. Manually entered names are preserved when changing configurations.

## Other changes since v0.1.11

- Istio Ambient options for experiments and independent application deployments,
  including waypoint replicas and resources.
- User requests and replies, administrative request handling and role promotion.
- Input-rate chart, import and interface fixes from the merged feature branches.

## Security

- Build KubePhos and managed components with Go 1.26.11, fixing the HTTP server
  vulnerability GO-2026-6859.
- Managed components: ClusterLens v1.3.2, mon-agent v0.0.11 and Mentat v0.3.9.

## Upgrade

Back up the installation and wait for active work to finish. Set
`KUBEPHOS_VERSION=v0.1.13` in the installation `.env`, then run `./update.sh` from
this release's archive or checkout. Add `--directory /path/to/installation` for a
custom installation path. If using a temporary local image, restore
`KUBEPHOS_IMAGE=ghcr.io/unict-cclab/kubephos` first.

The update applies the new user-request database migrations automatically.
Existing configurations, suites, comparisons, results and credentials are retained.
New managed component images are bundled with the release.

## Verification

Frontend regression tests, production build, bundle and theme checks; Go tests
and static analysis; isolated PostgreSQL tests for storage, API and execution;
installer tests. Authenticated browser checks covered comparison selection,
creator filtering, duplicate exclusion, editable plot labels, empty states and
full-width tables in the comparison and comparative configuration forms.
