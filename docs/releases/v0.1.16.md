# KubePhos v0.1.16

## Placement history and heatmaps

- Retain sampled application pod placement in metric datasets, including node,
  zone and cluster identity.
- Replay placement from the individual execution, with timeline controls and a
  service filter.
- Show total scheduled replicas by zone as a heatmap in Plots, with a discrete
  color scale and PDF/PNG export.
- Under All executions, average placement counts across runs aligned to workload
  start, using the shared duration and coarsest resolution. Missing observations
  remain distinct from zero replicas.

## Plot exports

- Show a loading indicator while preparing PDF and PNG files across result plots,
  heatmaps, application topology and load profile previews.
- Prevent repeated export clicks and restore controls after success or failure.
- Prepare large vector PDFs in small batches to keep the interface responsive.

## Configuration and interface

- Allow Online Boutique's redis-cart deployment to use the global initial replica
  count or a service-specific override.
- Display network bandwidth limits in Mbps while retaining the existing storage
  and API units.
- Improve form alignment when validation appears, compatible-service selector
  padding, and text wrapping in sharing dialogs and service overrides.
- Remove redundant field descriptions and standardize spacing in editors.

## Updates

- Retry temporary Keycloak administrator authentication failures during instance
  configuration synchronization. Rejected credentials still fail immediately,
  and identity server responses are excluded from user-facing errors.

## Upgrade

Back up the installation and wait for active work to finish. Set
`KUBEPHOS_VERSION=v0.1.16` in the installation `.env`, then run `./update.sh` from
this release's archive or checkout. Add `--directory /path/to/installation` for a
custom installation path. If using a temporary local image, restore
`KUBEPHOS_IMAGE=ghcr.io/unict-cclab/kubephos` first.

Existing configurations, suites, comparisons, results and credentials are
retained. Placement history is optional and requires newly collected datasets;
older results are preserved without synthesizing placement observations. The
metrics collector is updated to 0.9.0. No database migration is required, and
managed component versions are unchanged from v0.1.15.

## Verification

dependency audit with no reported vulnerabilities; 566 frontend tests; production
build, bundle and theme checks; regression tests
for plot export progress, vector PDF equivalence, placement aggregation, missing
