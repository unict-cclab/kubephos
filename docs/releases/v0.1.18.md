# KubePhos v0.1.18

## Standalone virtual machines

- Create standalone VMs from a ready template through Infrastructure → VM.
- Select the Proxmox server, CPU, memory, disk and network allocation.
- Follow provisioning activity, download the VM's SSH key and check SSH reachability.
- Delete a VM through its validated provisioning lifecycle.

## Cluster components and application settings

- Select the managed components installed on a cluster and reconcile changes on existing clusters.
- Validate application requirements against the components enabled on the selected cluster.
- Configure ambient Istio waypoint placement and resources.
- Configure persistent connections to node proxies.
- Improve dashboard links, resource readouts and focus stability while editing pool names.

## Upgrade

Set `KUBEPHOS_IMAGE=ghcr.io/unict-cclab/kubephos` and
`KUBEPHOS_VERSION=v0.1.18` in the installation `.env`, then run `./update.sh`
from this release's archive or checkout. Use `--directory /path/to/installation`
for a custom installation path.

No database migration is required. Managed component image versions are
unchanged from v0.1.17.
